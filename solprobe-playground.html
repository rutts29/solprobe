Existing tools detect crashes after they happen. SolProbe catches silent failures — thermal throttling, gradient explosions, NCCL timeouts, ECC errors — and diagnoses root causes before training runs are lost.

Key Capabilities

• Hybrid detection — edge thresholds in Rust (<1s) + central statistical analysis in Python
• 14 alert types — thermal, memory, XID, ECC, gradient, loss, NCCL, straggler, DiLoCo-specific
• LLM diagnosis — Claude API with structured tool_use, 7 recovery actions, RAG for similar incidents
• On-chain trust — 4 Solana Anchor programs for attestation, escrow, reputation, staking
• Apple Silicon — runs locally on M-series Macs via IOKit + MPS training demo

Why Solana?

In decentralized training networks like Prime Intellect's INTELLECT-2, workers are untrusted — anyone can contribute GPU compute. The system needs cryptographic proof that work was actually done, and economic incentives to punish cheating.

Attestation — Workers submit on-chain checkpoint hashes + GPU metadata. Verifiers confirm training actually happened, not just empty cycles.
Escrow — Job creators deposit SOL upfront. Workers get paid on verified completion, slashed on failure. No trust required.
Reputation — On-chain worker profiles track completion rate and slash history. Bad actors get priced out over time.
Staking — Workers stake SOL as collateral. Slashing links directly to SolProbe diagnosis IDs — the off-chain fault detection feeds the on-chain enforcement loop.

Solana over Ethereum: 400ms finality, ~$0.001 per attestation vs $2+. At scale (thousands of checkpoints/hour), cost matters.
