Ember is accent-only — reserve it for the mark's dot, single CTA, alert peaks, and ~1 brand moment per view. The rest of the app lives in ink + paper + ash.

Don'ts

Don't stretch
Don't rotate
Don't place on clashing color
Don't add glow/effects

Also: don't swap the ember for another color, don't change the waveform path, and don't re-kern the wordmark.

Applying across the app

Files ship in assets/logo/. Drop them into the dashboard's public folder and update the four places below.

// 1. Copy logo files into Next.js public folder
apps/dashboard/public/logo/
  ├─ solprobe-mark.svg            // primary (ink + ember dot)
  ├─ solprobe-mark-mono.svg       // currentColor for tinting
  ├─ solprobe-wordmark.svg        // horizontal lockup (light bg)
  ├─ solprobe-wordmark-dark.svg   // lockup for dark bg
  └─ favicon.svg                  // full-bleed tile

1. Sidebar brand. components/layout/Sidebar.tsx:

import Image from 'next/image';

<div className="flex items-center gap-2 px-3 py-4">
  <Image src="/logo/solprobe-mark.svg" alt="SolProbe" width={28} height={28} />
  <span className="font-bold tracking-tight">
    Sol<span className="text-muted-foreground font-medium">Probe</span>
  </span>
</div>

2. Favicon + metadata. app/layout.tsx:

export const metadata: Metadata = {
  title: 'SolProbe',
  description: 'Autonomous fault detection for distributed AI training',
  icons: { icon: '/logo/favicon.svg' },
};

3. Theme tokens. app/globals.css — add the ember accent and keep it scoped:

/* Ink & Ember tokens — paste into :root */
--brand: #FF6B35;           /* ember — accent only */
--brand-fg: #0a0a0f;        /* text on ember */
--brand-soft: #FFF4EE;      /* ember 6% tint */

/* Usage rules:
   • Sidebar active item  → bg var(--brand-soft), text var(--brand)
   • Primary CTA          → bg var(--brand), text var(--brand-fg)
   • Chart series accent  → var(--brand) for ONE series, never two
   • Status (ok/warn/crit) unchanged — ember is NOT a status color */

4. Auth / loading / empty states. Centered wordmark at 180×44. For a loading pulse, animate the ember circle:

<svg viewBox="0 0 120 120">
  {/* ...mark paths... */}
  <circle cx="64" cy="54" r="6" fill="#FF6B35">
    <animate attributeName="opacity" values="1;0.35;1"
             dur="1.4s" repeatCount="indefinite" />
  </circle>
</svg>

Clear space: ≥ 1/4 mark-height on all sides. Minimum size: 16px — below that use favicon.svg.

OG/social image: wordmark centered on 1200×630 #0a0a0f, ≥ 120px padding.

All files are plain SVG. The mono variant uses currentColor; the primary uses flat fills (no gradients) so it stays crisp at 16px.
